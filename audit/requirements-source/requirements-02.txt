## 1.1. Requirement Checklist үүсгэ

Өмнөх болон одоогийн бүх шаардлагыг нэгтгэсэн checklist үүсгэ.

Шаардлага бүр дараах төлөвтэй байна:

- COMPLETE — бүрэн хэрэгжсэн, шалгасан
- PARTIAL — хэсэгчлэн хэрэгжсэн
- MISSING — хэрэгжээгүй
- BROKEN — хэрэгжсэн боловч ажиллахгүй
- BLOCKED — гадаад эрх эсвэл мэдээлэл шаардлагатай

Requirement бүрийг тухайн код, database table, tutorial эсвэл UI component-той холбож шалга.

**Зөвхөн файл байгаа учраас COMPLETE гэж тэмдэглэж болохгүй.**

Ажиллаж байгаа эсэх, бодит өгөгдөлтэй эсэх, чанарын шаардлага хангасан эсэхийг баталгаажуул.

Аудитыг repository дотор Markdown report хэлбэрээр хадгал.

Дараа нь бүх MISSING, PARTIAL, BROKEN шаардлагыг хэрэгжүүлэх ажлаа үргэлжлүүл.

## 3.1. Tutorial бүрийн заавал байх бүтэц

### 1. Энэ алгоритм яагаад хэрэгтэй вэ?

Сурагчид тулгарч буй асуудлыг эхлээд үзүүл.

Алгоритм байхгүй үед ямар бэрхшээл гарч байгааг тайлбарла.

### 2. Энгийн шийдэл

Brute force эсвэл илүү хялбар аргаар яаж шийдэхийг харуул.

### 3. Гол ажиглалт

Энгийн шийдлээс илүү сайн шийдэлд хүргэх observation-ийг алхам алхмаар тайлбарла.

### 4. Алгоритмын үндсэн санаа

Тухайн алгоритм яг юу хийдэг, ямар invariant хадгалдгийг ойлгуул.

### 5. Алгоритм хэрхэн ажилладаг вэ?

Бодит, жижиг жишээгээр алхам бүрийг үзүүл.

### 6. Яагаад зөв ажилладаг вэ?

Correctness proof оруул.

Шаардлагатай үед induction, contradiction, exchange argument, loop invariant ашигла.

### 7. Яагаад хурдан ажилладаг вэ?

Time complexity-ийн томьёог зүгээр бичээд орхихгүй.

Яагаад ийм нийлмэл байдалтай болдгийг математик болон intuitive талаас нь тайлбарла.

### 8. C++17 implementation

Кодыг логик хэсгүүдэд хуваа:

- Data structures
- Initialization
- Main algorithm
- Updates/transitions
- Result computation
- Complete code

Хэсэг бүрийг ойлгомжтой тайлбарла.

### 9. Edge cases

Хамгийн чухал boundary cases-ийг харуул.

### 10. Common mistakes

Түгээмэл алдаа болон counterexample үзүүл.

### 11. Алгоритмын бусад хувилбарууд

Related variations-ийг тайлбарлаж, холбогдох tutorial руу чиглүүл.

### 12. Хэзээ ашиглах вэ?

Бодлогын ямар шинж тэмдэг тухайн алгоритмыг санал болгодгийг тайлбарла.

### 13. Practice problems

Warm-up → Standard → Observation → Application → Challenge → Olympiad extension.

### 14. Priority problems

Тухайн сэдвийг эзэмшихэд хамгийн чухал бодлогуудыг ⭐ Priority гэж тодруул.

### 15. Дүгнэлт ба checklist

Сурагч юу ойлгож, юу хийж чаддаг болсон байх ёстойг тодорхойл.
